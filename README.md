# 校园失物招领

2026 秋软件工程第二次结对作业 —— 程序实现。

一个纯前端（HTML + CSS + JavaScript）实现的「校园失物招领」网页应用：集中发布寻物 / 招领信息，支持按关键词搜索、按类别与地点筛选、查看详情与联系方式、一键复制联系方式，以及由发布者将信息标记为「已找到 / 已归还」。数据保存在浏览器本地（localStorage），**无需服务器、无需数据库、无需安装依赖**，用谷歌浏览器直接打开即可运行。

> 本项目为第二次结对作业的正式实现；第一次作业的原型页面保留在 `prototype.html` 与 `flowcharts.html` 中，可供对照。

### 各模块职责

| 文件          | 职责                                                         |
| ------------- | ------------------------------------------------------------ |
| `js/core.js`  | 与界面无关的纯函数，独立可测试（UMD 写法，浏览器与 Node 通用）。包含搜索、筛选、排序、表单校验、状态更新、相对时间格式化、统计等。 |
| `js/store.js` | 封装 `localStorage` 的读写。首次访问自动写入 8 条示例数据，提供增、删、改、查、重置等接口。 |
| `js/utils.js` | DOM 相关的通用工具：`escapeHtml`（渲染用户输入前转义，防止 XSS 注入）、`debounce`（搜索防抖）、`copyText`（复制联系方式，带降级方案）。 |
| `js/app.js`   | 单页应用核心：根据 `state.view` 在「首页 / 详情 / 发布 / 我的发布」四个视图间切换，绑定交互事件。 |

### 数据模型

每条信息包含以下字段：

```
{
  id:         唯一标识
  type:       'lost'(寻物启事) | 'found'(失物招领)
  title:      物品名称
  category:   类别（证件卡类 / 电子数码 / 生活用品 / 文具书籍 / 衣物鞋帽 / 其他）
  location:   地点（教学楼 / 图书馆 / 食堂 / 宿舍区 / 田径场 / 其他）
  time:       发布时间戳（毫秒）
  contact:    联系方式
  description: 物品描述
  image:      图片（base64，可选）
  status:     'active'(进行中) | 'resolved'(已找回/已归还)
  publisher:  发布者
}
```

## 二、使用说明（测试人员如何运行）

### 运行网页

1. 下载 / 克隆本项目全部文件，保持目录结构不变（`index.html` 必须和 `css/`、`js/` 在同一目录下）。
2. **使用谷歌浏览器（Chrome）** 双击打开 `index.html`，即可看到首页。
3. 无需联网、无需安装任何依赖、无需启动服务器。

### 功能操作指引

| 功能              | 操作                                                         |
| ----------------- | ------------------------------------------------------------ |
| 浏览信息          | 打开首页即可看到全部失物招领信息列表                         |
| 按类型筛选        | 点击「全部 / 失物招领 / 寻物启事」分段按钮                   |
| 按类别 / 地点筛选 | 使用搜索框下方的「类别」「地点」下拉框                       |
| 排序              | 使用「最新发布 / 最早发布」下拉框                            |
| 搜索              | 在顶部搜索框输入关键词（支持按名称、地点、描述模糊搜索，不区分大小写） |
| 查看详情          | 点击任意信息卡片                                             |
| 联系发布者        | 在详情页点击「联系发布者」或「复制联系方式」，联系方式会复制到剪贴板 |
| 发布信息          | 点击右上角「＋ 发布信息」，选择类型并填写表单后点「发布」    |
| 我的发布          | 点击右上角「我的发布」，查看 / 管理自己发布的信息            |
| 标记状态          | 在「我的发布」或自己发布的详情页，点击「标记已找回 / 已归还」 |
| 删除信息          | 在「我的发布」或自己发布的详情页，点击「删除」               |
| 重置数据          | 在「我的发布」页底部点击「重置示例数据」，恢复初始数据       |

### 验证要点（助教可参考）

- 首页展示 8 条示例数据，顶部统计卡片显示总数 / 招领 / 寻物 / 已解决。
- 搜索「校园卡」能过滤出对应信息；搜索「耳机」能命中名称与描述。
- 发布一条信息后，会跳转到「我的发布」并显示该信息；刷新页面后数据仍在（localStorage 持久化）。
- 将一条信息标记为「已找回 / 已归还」后，列表中该信息会显示灰色「已找回 / 已归还」标签。
- 表单必填项（物品名称、地点、联系方式）为空时，会在对应字段下方显示红色提示，无法提交。

## 三、运行单元测试

本项目单元测试使用 **Node.js 内置的 `node:test` 模块**，无需安装 Mocha、Jest 等任何第三方依赖。

**前置条件**：本机已安装 Node.js（建议 18 及以上版本）。

在项目根目录执行：

```bash
node --test tests/core.test.js
```

或：

```bash
node tests/core.test.js
```

预期输出：`pass 21`（21 个测试用例全部通过）。

测试覆盖 `js/core.js` 中的核心纯函数，包括：搜索、筛选、排序、相对时间格式化、表单校验、状态更新、按 id 查找、状态文案、统计等。

## 四、附加特点

除作业要求的核心功能外，本项目还实现了以下人性化设计：

1. **按类别 + 地点组合筛选**：除类型外，还可按物品类别、地点多维度筛选，快速定位目标。
2. **一键复制联系方式**：详情页点击按钮即可复制发布者联系方式，减少手动输入错误。
3. **图片上传（自动压缩）**：发布时可上传物品照片，前端用 Canvas 自动压缩到 600px，避免占用过多本地存储。
4. **相对时间显示**：列表显示「刚刚 / N 分钟前 / N 小时前 / 昨天」等友好时间。
5. **实时搜索防抖**：输入关键词时防抖刷新结果，减少不必要的渲染，且保持输入框焦点。
6. **表单校验 + 友好错误提示**：必填项、超长字段均有即时校验与红色提示。
7. **二次确认弹窗**：标记状态、删除信息等敏感操作前会弹出确认框，防止误操作。
8. **空状态提示**：搜索无结果、我的发布为空时展示友好引导。
9. **示例数据一键重置**：测试人员可随时恢复初始数据。
10. **XSS 防护**：所有用户输入渲染前统一经 `escapeHtml` 转义。
